## Frozen policy

`exact-form-conflicts-v1`, implemented in `evaluation/risk_queue.py`:

- Qwen: native valid GPT, absolute GPT–baseline gap≥2, at least one usable sense.
- Review eligibility: GPT technical failure or initial GPT–baseline gap≥2. Qwen
  cannot veto an initially eligible conflict;4vs5 alone never creates a card.
- Lexicographic priority: GPT failure, Qwen failure, Qwen–GPT gap≥2, score span,
  initial gap, missing contexts, multiple POS, SHA256(`qwen-pilot-v1:`+ID).
- Scores remain separate: operational baseline; research GPT proposal or explicit
  baseline fallback after a technical failure. No averaging or model voting.
- No numeric correctness probability. Missing evidence is uncertainty, never proof
  of obscurity. No padding the review queue to50.

No alternative thresholds/rankings were searched. The implementation rejects human
label columns, partial/mismatched IDs, invalid scores and off-route Qwen results.
CSV artifacts expose preliminary/final routing status; only final routing feeds UI.

## Reproduction

Working checkout: `build/d1/risk-plan-pr`; Python runtime:
`build/d1/exact-form-code/.venv/bin/python`, `PYTHONPATH=src`.

Public commands (from the checkout):

```sh
PYTHONPATH=src python scripts/export_audit_judge_evidence.py \
  --forms FORMS.csv --vocabulary VOCABULARY.csv \
  --audit VERIFIED_AUDIT_DIRECTORY --output NEW_EVIDENCE_DIRECTORY
PYTHONPATH=src python scripts/build_risk_queue.py \
  --baseline BASELINE.csv --evidence EVIDENCE.csv --gpt GPT.csv \
  --output NEW_ROUTE_DIRECTORY
PYTHONPATH=src python scripts/build_risk_queue.py \
  --baseline BASELINE.csv --evidence EVIDENCE.csv --gpt GPT.csv \
  --qwen ROUTED_QWEN.csv --output NEW_FINAL_DIRECTORY --review-budget 50
```

Baseline projection: `word_id,word,baseline_level,wordfreq`; judgment projection:
`word_id,word,status,rarity_level`. Extra label/metadata columns are rejected.
Keep zero-length native scores only for explicit failures. Qwen CSV covers exactly
the eligible route; an empty header-only CSV is allowed for a zero-route campaign.

Local immutable campaign: `build/d1/1000-judges-2026-10-31/`.
`policy.json`, `gpt/protocol.json`, `inputs-final/manifest.json` pin the run.
`verify_policy.py` reproduces the150-rule check. `gpt/run.py` resumes identical
native sessions from receipts; `prepare_qwen.py` requires1000 completed GPT records;
`qwen/run.py` resumes the local route. `finish.py` exports final routing, report,
source flags and review pack. `audit.py` independently verifies the entire result;
`--inputs-only` is safe before inference finishes. Raw lexical text, native exchanges
and per-form CoRoLa signals remain local; only aggregate research outputs published.
